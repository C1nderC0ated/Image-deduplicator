# Image Inventorization - package requirements, by stage.
#
# EASIEST: don't use this file. Run the setup helper - it detects your GPU,
# picks the right PyTorch build, shows every command and asks before running:
#     Windows        Check-Image-Tools.bat   (offers setup when something is missing)
#     Linux / macOS  ./imgdedup.sh setup
#
# PREREQUISITES - these are not in the list below, because they are what
# RUNS the list below. Neither is guaranteed to come with Python:
#
#   pip    Packaged separately on most Linux distros. Without it every
#          command here fails with "No module named pip", which looks like
#          a broken toolkit rather than a missing system package.
#            Arch            sudo pacman -S python-pip
#            Debian/Ubuntu   sudo apt install python3-pip
#            Fedora          sudo dnf install python3-pip
#
#   venv   Required, not optional, on Arch, Debian 12+, Ubuntu 23.04+,
#          Fedora 38+ and Homebrew: those mark their Python externally
#          managed (PEP 668) and pip refuses to install into it at all, so
#          a virtual environment is the only route. Debian splits it out:
#            sudo apt install python3-venv
#          Where pip is missing but venv works, a venv supplies its own pip.
#
#   Check both, per interpreter:   ./imgdedup.sh doctor
#
# Minimal (Collect only):
pillow>=10.0.0

# Semantic stage (Embed) - transformers from PyPI, torch installed SEPARATELY
# because the right build depends on your hardware. Pick ONE:
#
#   CPU only (always works):
#     pip install torch --index-url https://download.pytorch.org/whl/cpu
#   NVIDIA GPU (CUDA):
#     pip install torch --index-url https://download.pytorch.org/whl/cu132
#   AMD GPU on LINUX (ROCm):
#     pip install torch --index-url https://download.pytorch.org/whl/rocm7.2
#   Intel GPU (XPU):
#     pip install torch --index-url https://download.pytorch.org/whl/xpu
#
#   These version suffixes MOVE - cu128 became cu132, rocm6.4 became rocm7.2.
#   The setup helper reads the current list from download.pytorch.org instead
#   of trusting a number written here, so prefer it over copying these lines.
#
#   AMD GPU on WINDOWS: not from PyPI. AMD publishes ROCm wheels directly at
#   repo.radeon.com, and ONLY for Python 3.12 (they are full-ABI cp312 wheels,
#   so 3.13/3.14 cannot load them - this is AMD's build matrix, not a setting).
#   Install Python 3.12 alongside, run setup with it, and point just the Embed
#   stage at it via IMGDEDUP_PYTHON. See README, "AMD GPUs".
#
#   torchvision is NOT needed by anything here, and a stale one breaks
#   transformers - do not install it "just in case".
#
#   Installed the CPU build by mistake (version shows "+cpu")? Uninstall first:
#     pip uninstall torch
#   then install from the right index - a +cpu wheel can never use a GPU.
#
transformers>=4.43.0
